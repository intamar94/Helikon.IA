# Revisión del ciclo de dominio

## Flujo obligatorio

1. Aprender
2. Practicar
3. Evaluar
4. Aprobar → dominio confirmado
5. Fallar → volver a aprendizaje/refuerzo

El desbloqueo nunca depende de una acción manual del usuario.

## Evidencia mínima

La evaluación debe registrar resultado, intento y si la competencia fue demostrada.

## Siguiente mejora

Las evaluaciones deben identificar habilidades fallidas para dirigir el refuerzo al contenido concreto, y el límite de oportunidades debe ser aplicado por el motor, no solamente mostrado en pantalla.
