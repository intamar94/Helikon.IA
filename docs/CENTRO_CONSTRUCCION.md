# Centro de Construcción de Helikon.IA

El Centro de Construcción muestra el estado real del desarrollo de Helikon sin confundir código escrito con funcionalidad validada.

## Estados

- `pendiente`: todavía no iniciado.
- `en_construccion`: hay trabajo activo.
- `validado`: implementado y comprobado.
- `requiere_correccion`: existe una implementación, pero falló una validación.

## Etapas de cada reto

1. Diseño
2. Contenido
3. Aprender
4. Practicar
5. Evaluar
6. Adaptación
7. Integración
8. Build
9. Validación

## Reto 05 — Testing

El reto debe enseñar testing desde la necesidad de comprobar comportamiento, no desde la memorización de definiciones. Debe incluir ejemplos reales, práctica, casos que fallen, lectura de resultados, corrección y transferencia.

La barra de progreso del Centro debe calcularse a partir de estados de etapas verificables y no de una estimación manual.
