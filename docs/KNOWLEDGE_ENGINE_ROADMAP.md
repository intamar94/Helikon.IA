# Helikon.IA — Motor de conocimiento

## Flujo objetivo
Fuente → evidencia → concepto → relación → contradicción → hipótesis → nueva pregunta → conocimiento validado.

## Reglas
- Diferenciar hechos, interpretaciones, hipótesis y preguntas abiertas.
- Mantener procedencia de cada afirmación.
- Detectar contradicciones en fuentes.
- No presentar hipótesis como hechos.
- Mantener una zona de conocimiento inexplorado o inconcluso.
- Priorizar nuevas preguntas que puedan reducir incertidumbre.

## Vercel
La consolidación del motor, pruebas y datos se realiza antes del despliegue. Vercel queda como integración final.
