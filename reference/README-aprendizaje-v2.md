# Arquitectura de aprendizaje v2

Cada reto sigue una progresión basada en evidencia:

1. **Entrar en el mundo** — contexto, misión e ilustración adaptada.
2. **Aprender** — descubrir, predecir, explorar, explicar, recuperar, transferir y romper.
3. **Practicar** — aplicar con guía decreciente.
4. **Evaluar** — resolver una variante nueva.
5. **Dominar** — desbloquear únicamente cuando existe evidencia suficiente.

La Fase 0 no pretende enseñar el contenido. Su función es crear propósito y curiosidad antes de la experiencia de aprendizaje.
