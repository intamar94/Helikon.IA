# Helikon.IA — Motor de aprendizaje v2

El reto 01 se utiliza como laboratorio pedagógico antes de escalar a los demás nodos.

## Principio

Aprender no es leer una explicación y pulsar continuar. Cada concepto debe pasar por una secuencia de evidencia:

1. Contexto — el concepto aparece dentro de un problema.
2. Predicción — el estudiante anticipa qué ocurrirá.
3. Exploración — manipula variables y observa consecuencias.
4. Explicación — reconstruye la idea con sus propias palabras.
5. Recuperación — recuerda sin volver a mirar.
6. Transferencia — aplica el concepto en un contexto diferente.
7. Romper — identifica límites, errores y casos inesperados.
8. Preparación — resume las ideas esenciales y pasa a práctica.

## Principio de dominio

Un nodo no se desbloquea por decisión del usuario. El estado depende de evidencia registrada.

APRENDER → PRACTICAR → EVALUAR → DOMINADO

Si falla la evaluación, vuelve a APRENDER y el sistema conserva el intento y el punto que necesita refuerzo.

## Evolución futura

El componente específico del reto 01 es un prototipo. La siguiente fase debe convertir esta secuencia en un motor declarativo capaz de recibir una definición de nodo y generar/adaptar experiencias para programación, biología, física, matemáticas, ingeniería y otras disciplinas.

La experiencia debe medir comprensión, aplicación, transferencia y capacidad de detectar fallos; no solamente memoria de definiciones.
